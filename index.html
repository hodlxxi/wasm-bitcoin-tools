HODLXXI tools that run Bitcoin Core in your browser.

Inspect public P2WSH Bitcoin contracts independently with the HODLXXI Contract Verifier, alongside three original Bitcoin Core tools. Each tool runs an unmodified Bitcoin Core in an offline WebAssembly guest. Only an optional, explicitly requested public-address lookup contacts mempool.space.
